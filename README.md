# Tuvora for Claude Code

Connects Claude Code to your [Tuvora](https://tuvora.co) account so you can tidy your Live TV in plain words: "hide the adult channels", "make a Sports group with my football channels". Every change is previewed first and saved only when you confirm. Changes sync to your Tuvora apps.

## Install

```
/plugin install tuvora --marketplace paradox-kush/tuvora-claude-plugin
```

Then run `/mcp`, pick **tuvora**, and sign in to Tuvora when the browser opens. Tap **Allow** on the consent screen.

## What it can do

Account overview, list playlists, list Live TV categories and groups, search channels, preview and apply changes (hide, show, pin, reorder, custom groups), delete a group, reset customisation. Live TV editing works for Xtream playlists.

## What it can't do

See or change playlist addresses, usernames or passwords; change profile PINs; sign devices out; delete your account.
